---
USER: Walk me through the workflow for an RL pipeline. We 3D printed a robot,
wrote servo control code, want to train in simulation. What do you need?
URDF? All the above?

ASSISTANT: Laid out the sim-to-real workflow:
1. Physical model — URDF + meshes + inertias, motor model for LX-16A
   (position-only, approximate as PD in sim)
2. Simulator — MuJoCo (standard) or Isaac Lab (GPU parallel)
3. MDP — obs: joint pos/vel + base quat + ang vel + last action + cmd vel;
   act: target joint angles; reward: velocity tracking + upright + energy +
   smoothness; termination: tilt > 45° or time
4. SENSOR GAP — robot has no IMU, biped balance impossible without one
5. Sim-to-real — domain randomization + system ID from real rollouts
6. Training — PPO, ~1e8 steps, curriculum

ASSISTANT: For a biped: no. Policy learns IMU as primary feedback for tilt

BNO085 is $20 with onboard fusion. Described Onshape → URDF workflow using
`onshape-to-robot` tool (not native Onshape export), emphasizing that
setting accurate material densities is the biggest lever for sim-to-real
accuracy.
